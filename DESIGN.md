# Noor visual identity

Emerald #103F35 is the primary brand surface; ivory #F7F5EE is the daytime canvas; gold #E4CF99 is a restrained accent on emerald. Dark mode uses #0C1E19 canvas and #142A23 surfaces. Normal body text is not rendered in gold on ivory.

The prayer time is the primary focal point. A serif display face pairs with Android’s readable sans body type and tabular-style monospace time labels. All dimensions use dp and typography uses sp. Scrollable layouts accommodate font scaling; the monthly table intentionally scrolls horizontally.

The hero’s mosque silhouette and low-contrast geometric lattice are decorative Canvas primitives, excluded from TalkBack. Interactive icons have spoken labels; bottom-navigation icons use their adjacent text label. Arabic direction comes from Android locale resources, not hand-reversed rows.

Adaptive icon: 108 × 108 viewport, emerald background and an ivory/gold crescent-minaret mark within the central safe area. Android 13 monochrome masks use the foreground silhouette. The system splash uses the same mark with no artificial delay. The app name is displayed on onboarding; Android’s standard splash icon layout is preserved.
